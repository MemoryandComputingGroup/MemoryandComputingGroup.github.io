# Fudan Memory and Computing Group

**复旦大学存储与计算课题组**

*Enabling the Future of Memory and Intelligence · 以存算之力，启智能未来*

The Fudan Memory and Computing Group studies emerging memory devices and brain-inspired computing. Our work connects device physics, algorithms, circuits, and chip architectures to develop efficient hardware for artificial intelligence.

[Visit our website](https://memoryandcomputinggroup.github.io/) · [Research](https://memoryandcomputinggroup.github.io/research.html) · [People](https://memoryandcomputinggroup.github.io/people.html) · [Publications](https://memoryandcomputinggroup.github.io/publications.html) · [Join us](https://memoryandcomputinggroup.github.io/join.html)

## Research

- **[Emerging Memory and Integration](https://memoryandcomputinggroup.github.io/research-emerging-memory.html):** Emerging memory devices, artificial neurons and synapses, and their integration into sensing and computing circuits.
- **[Hardware–Algorithm Co-Design for Neuromorphic Computing](https://memoryandcomputinggroup.github.io/research-hardware-algorithm-codesign.html):** Algorithms, circuits, and architectures designed together for neural-signal processing, sensing, and other applications under practical hardware constraints.
- **[Neuromorphic Chips Based on Emerging Memory](https://memoryandcomputinggroup.github.io/research-neuromorphic-chips.html):** Digital, analog, and mixed-signal chips and architectures for efficient brain-inspired computation.
